# Contributing

Thanks for your interest in Placedv Query.

1. Fork the repository and create a focused branch for your change.
2. Install dependencies with `npm ci` and configure a local `.env` using `.env.example`.
3. Run `npm run lint` and `npm test` before opening a pull request.
4. Describe the user-visible change and any database migration or configuration changes.

Do not include real credentials, database dumps, SQLite uploads, or personal data in commits or issues. Keep pull requests focused and include or update tests for behavior changes.
